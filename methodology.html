Methodology

How the chart is calculated.

Last updated: June 17, 2026

Vedic Kundli uses a hosted Python backend with deterministic astronomy and Vedic chart settings. The app is designed to make the calculation path traceable instead of opaque.

Calculation stack

  • Skyfield with the JPL DE440 ephemeris for planetary positions
  • PyERFA for Earth orientation and precession-related formulas
  • Python zoneinfo for timezone and DST rules
  • ICRC Lahiri ayanamsa
  • Mean lunar node with Ketu exactly opposite Rahu
  • Whole-sign houses
  • Vimshottari dasha sequencing

Input rules

  • Birth dates must use DD/MM/YYYY
  • Birth time is a local wall-clock time
  • An IANA timezone is required
  • Backward DST transitions use the fold value
  • Different calculators may disagree if they use a different ayanamsa, node model, house model, or timezone source

Interpretation limits

The app provides educational and cultural interpretation only. It does not make guaranteed claims about health, money, law, relationships, or destiny.

Results remain sensitive to exact birth time, timezone accuracy, and coordinates.
